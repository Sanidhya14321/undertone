# Undertone 0.1.1-beta.1

[Open Undertone](https://undertone.vercel.app) · [Voice studio](https://undertone.vercel.app/studio) · [Extension](https://undertone.vercel.app/extension)

- Shorter production URL, with updated SEO and extension links.
- Scrollable workspace navigation, mobile drawer with keyboard support, and complete mobile public navigation.
- Persistent light/dark mode throughout the website and extension.
- Remembered API keys, optional session-only use, and removal on disconnect. The extension restores remembered connections after browser restart.
- Removed unused profile controls; updated privacy and connection documentation.

Keys are stored unencrypted when remembering is enabled: use a trusted device. Website and extension connections are separate. Download and reload the updated extension to get these fixes.

Projects and audio remain local to each browser and site origin. Existing work is still available at the [old studio](https://undertone-voice-workspace.vercel.app/studio); export projects and download audio before switching. Keys do not migrate between domains.

Provider operations require your own Fish Audio key and credit. Automated provider checks use controlled responses; live billable requests and native extension playback have not been verified with a real key for this release.

This remains an independent beta, unaffiliated with Fish Audio. Uploads are limited to 4 MB. The extension uses unpacked developer installation, not a browser-store listing.
