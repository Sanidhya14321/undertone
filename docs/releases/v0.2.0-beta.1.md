# Undertone 0.2.0-beta.1

- Translate selected text, full scripts, dialogue turns and transcripts on supported desktop browsers with on-device language models. No extra translation key or cloud fallback.
- Review/edit before applying; preserve originals and dialogue speakers. Transcript translation leaves original subtitle timing intact.
- New persistent extension translation side panel with Listen and Open in studio actions. Reload unpacked extension files; this update adds the sidePanel permission, with no additional host access.
- Versioned Unicode handoff carries optional translation provenance without keys. Existing imports/projects remain compatible.
- Speech generation and listening still require Fish Audio API credit. Browser/device/language-pair support and first-use downloads vary. Unsupported environments retain existing speech tools and manual translation input.

## Verification notes

Automated coverage includes on-device API mocks, mixed-language segmentation, preserved speech directions and dialogue identities, reversible selection replacement, cancellation/stale results, language-resource failures and activation retry, extension draft recovery, versioned Unicode handoffs, length limits, and translated-text playback routing. No billable Fish Audio request was made.

The connected in-app browser exposed Translator but failed native Hindi language-resource creation. The application’s failure/review path and manual Hindi/Spanish review-to-studio flows were checked; this is not a claim of successful native translation. Actual first-use language downloads and extension side-panel playback still need verification in a supported desktop Chrome/device. Existing speech workflows remain usable when local translation is unavailable.
