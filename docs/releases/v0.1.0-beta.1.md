Undertone's first public beta brings Fish Audio speech, voice creation, transcription, and browser text capture into one workspace.

- **[Open the studio](https://undertone-voice-workspace.vercel.app/studio)**
- **[Read the workflow guides](https://undertone-voice-workspace.vercel.app/guides)**
- **[Install the companion](https://undertone-voice-workspace.vercel.app/extension)**

## Included

Direct expressive text to speech and multi-speaker dialogue; browse voices; create a permissioned private voice or design auditions; transcribe recordings and export TXT/SRT/VTT. Projects and generated takes save in the browser.

The Chrome/Edge MV3 companion captures explicit selections, sends listening requests directly to Fish Audio, and opens selected text in the studio. Its key stays in browser session storage.

This release also includes public guides, SEO metadata, self-hosted fonts, contribution documents, security reporting, and dependency updates. Original Undertone code is licensed under Apache 2.0; third-party notices are retained.

## Download and verify

Download `undertone-extension-v0.1.0-beta.1.zip` and `SHA256SUMS.txt`. Verify with `sha256sum -c SHA256SUMS.txt` on Linux, or `shasum -a 256 -c SHA256SUMS.txt` on macOS. On Windows, use `Get-FileHash .\undertone-extension-v0.1.0-beta.1.zip -Algorithm SHA256` and compare the digest.

Unzip, open `chrome://extensions` or `edge://extensions`, enable Developer mode, and load the folder containing `manifest.json`. Chrome/Edge 124+ is required. The package points to the public Undertone studio. It is not a browser-store publication.

## Before using the beta

Bring your own Fish Audio key; operations use your API credit. Uploads are limited to 4 MB. Audio and projects are local to the current site and browser. Subtitle exports retain original timestamps and words; transcript text corrections apply to TXT. Language settings do not translate scripts.

Unit and HTTP smoke checks cover the app and integration boundaries without billable calls. Live Fish Audio generation and installed-extension playback have not been certified by those automated checks.
