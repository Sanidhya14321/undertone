# Roadmap

These are candidates for future work, not shipped capabilities or dated commitments.

## Next validation work

- Exercise live Fish Audio speech, dialogue, cloning, design, and transcription with authorized test credit and permissioned recordings.
- Test native Chrome/Edge playback, offscreen lifecycle, capture restrictions, and extension upgrades across supported browsers.
- Collect indexing and query data after owner verification in Search Console.

## Possible product improvements

- Better caption correction and timestamp realignment, with explicit export behavior.
- Import/restore of portable project backups and a clearer migration path between origins.
- Long-recording handling through an intentionally designed upload/job service.
- A browser-store release after native testing, privacy review, and owner account setup.

Cloud synchronization, telemetry, cloud translation, telephony, and hosted agents are not included in the current release. On-device translation is available on supported desktop browsers; remembered credentials are an explicit device-local option. Proposals involving them need a concrete user benefit and a reviewed change to the current data boundary.
