# Getting help

- [Workflow guides](https://undertone-voice-workspace.vercel.app/guides): speech, browser listening, and subtitles.
- [Troubleshooting](https://undertone-voice-workspace.vercel.app/help): keys, provider errors, uploads, local storage, and extension capture.
- [GitHub Discussions](https://github.com/Sanidhya14321/undertone/discussions): usage questions and ideas.
- [Bug reports](https://github.com/Sanidhya14321/undertone/issues/new/choose): reproducible application problems.
- [Private security reports](https://github.com/Sanidhya14321/undertone/security/advisories/new): potential vulnerabilities.

For billing, API-credit balances, account access, or provider model availability, use Fish Audio's support and documentation. Undertone is an independent project and cannot modify a Fish Audio account.

This is a community-maintained beta with no support SLA. Share minimal, sanitized examples. Never publish a key or a recording you do not have permission to share.
